# 팔도한자 · 한자로 읽는 우리 땅

**▶ 바로 하기: https://gavin19600.github.io/paldo-hanja/**

전국 지도 위의 지명, 동네, 문화재, 산, 강·호수, 역사 인물·사건, 학교 이름을 한자로 보고 한글 독음을 타자로 치는 웹 게임입니다. 지역을 고르면 **미리 익히기**(카드), **초성으로 풀기**, **퀴즈 풀기** 중에서 고를 수 있습니다.

`index.html` 한 장에 지도와 문제 자료가 모두 들어 있어서, 브라우저로 열기만 하면 됩니다.

## 들어 있는 문제

| 탭 | 범위 | 개수 |
|---|---|---|
| 지명 | 전국 시·군, 서울 25개 구, 제주 읍·면 | 198 |
| 동네 | 전남·광주 읍·면·동 | 356 |
| 문화재 | 전국 9개 권역 | 543 |
| 산 | 전국 | 172 |
| 강·호수 | 전국 | 130 |
| 역사 | 인물 82명, 사건 57건 | 139 |
| 학교 | 전남·광주 고등학교·중학교 | 364 |

## 폴더 구성

- `index.html` — 게임 페이지
- `data/` — 문제 원본 목록 (`한자|독음|위치|설명|경도|위도|종류` 형식)
  - `heritage-base.txt`, `extra.txt` — 문화재
  - `mount.txt` — 산 / `river.txt` — 강·호수 / `place.txt` — 지명 / `hist.txt` — 역사
  - `dong.txt` — 전남·광주 읍·면·동 한자 (`시군코드 독음=한자 …`)
  - `school.txt`, `mid.txt` — 전남·광주 고등학교·중학교 (`이름=한자@읍면동`)

## 알아둘 점

- **한자 표기와 설명은 검토가 필요합니다.** 대부분 자료와 대조하지 않고 작성했습니다. 틀린 곳은 `data/` 파일을 고친 뒤 페이지를 다시 만들어야 반영됩니다.
- **학교 탭**에는 지명이나 일반 낱말로 된 교명만 들어 있습니다. 고유한 교명(문태고, 영흥고 등)은 한자를 확인한 뒤 추가할 예정입니다.
- **학교별 점수 누적**은 Claude에 올린 페이지에서만 작동합니다. GitHub Pages 등 다른 곳에서 열면 점수는 각자의 기기에만 저장됩니다.
- 그림은 모두 직접 그린 SVG라 저작권 문제가 없습니다.
